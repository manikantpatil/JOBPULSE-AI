# JOBPULSE AI — Job Market Intelligence Dashboard

An interactive job-market analytics dashboard built with Python, Streamlit, Pandas, and Plotly.

## Features
- Interactive job listing filters
- Job market overview and visualizations
- AI, Machine Learning, Python, SQL, Power BI, and Data Science skill demand analysis
- Job listing explorer
- CSV export of filtered results

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## Installation

Clone the repository:

    git clone https://github.com/manikantpatil/JOBPULSE-AI.git

Enter the project directory:

    cd JOBPULSE-AI

Install dependencies:

    pip install -r requirements.txt

Run the dashboard:

    streamlit run dashboard_v2.py

## Dataset
The dashboard expects a CSV file at:

    data/processed/cleaned_jobs.csv

Use a dataset you have permission to share. Do not commit private or confidential data.
